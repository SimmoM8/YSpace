# 🚀 Yspace – User Stories

## 👤 Visitor *(not logged in)*

1. **Browse routes**  
   *As a visitor, I want to see a list of available routes so that I can discover where I can travel.*

2. **Search flights**  
   *As a visitor, I want to search flights by departure location and destination so that I can find a trip that suits me.*

3. **View flight details**  
   *As a visitor, I want to see detailed information about a specific flight (price, departure time, available seats) so that I can decide whether to book.*

4. **View available flights**  
   *As a visitor, I want to see a list of available scheduled flights for a route, with price, departure time, and available seats*

5. **Register an account**  
   *As a visitor, I want to create an account with my email and password so that I can make bookings.*

---

## 👩‍🚀 Space Tourist *(logged in)*

5. **Log in**  
   *As a registered user, I want to log in so that I can access my bookings and make new ones.*

6. **Book a flight**  
   *As a user, I want to select a flight and choose the number of seats so that I can reserve my trip.*

7. **Book multiple flights in one order**  
   *As a user, I want to add several flights to a single booking (e.g., Earth → Mars → Europa) so that I can plan a multi-leg journey.*

8. **View my bookings**  
   *As a user, I want to see a list of my past and upcoming bookings so that I can keep track of my trips.*

9. **Cancel a booking**  
   *As a user, I want to cancel a booking so that I can free up seats if my plans change.*

10. **See booking confirmation details**  
    *As a user, I want to view the confirmation after booking, including price breakdown and flight details, so that I have all information in one place.*

11. **Update my profile**  
    *As a user, I want to edit my name and contact information so that my details are up to date.*

---

## 🛠️ Admin

12. **Add a new route**  
    *As an admin, I want to create a new route between two spaceports so that it becomes available for flights.*

13. **Schedule a flight**  
    *As an admin, I want to add a new flight to an existing route, specifying date, spacecraft, price, and total seats so that customers can book it.*

14. **Edit a flight**  
    *As an admin, I want to modify flight details (price, spacecraft, time) so that I can correct mistakes or adjust offers.*

15. **Cancel a flight**  
    *As an admin, I want to cancel an entire flight so that no further bookings are made on it (and notify affected customers).*

16. **View all bookings**  
    *As an admin, I want to see all customer bookings so that I can monitor sales and capacity.*

17. **Manage spacecraft inventory**  
    *As an admin, I want to add or retire spacecraft so that the fleet is up to date.*

18. **Manage spaceports**  
    *As an admin, I want to add new spaceports (planets, moons, stations) so that routes can be created to them.*

---

## 🎯 MVP Priority
1. Browse routes
2. Search flights
3. View flight details
4. Register & log in
5. Book a flight
6. View my bookings
7. Cancel a booking
8. Admin: add route & schedule flight
